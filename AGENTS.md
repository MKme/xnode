# Publication instructions

When the user explicitly instructs you to publish requested work, complete publication to the repository's default branch unless the user explicitly names another destination. A local commit, review branch or pull request alone does not complete a request to publish to the default branch.

Inspect current default-branch changes, preserve unrelated work, integrate safely, run applicable checks, then push through the repository's normal allowed process. Verify the remote default-branch commit and the user-visible result, including rendered README/documentation and image links when relevant. Report the published commit and documentation URLs.

This rule grants no permission for future unsolicited publication, force pushes, bypassing branch protections, or disclosure of private information. Deployment, releases and hardware flashing require their own authorization. Before a push, check for automatic deployment implications and report any material unapproved consequence before triggering it.
